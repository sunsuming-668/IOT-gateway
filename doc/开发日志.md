### 2. 遇到的问题与解决

#### 问题1：WSL2 DNS解析失败
**现象：** `sudo apt install` 报 `Temporary failure resolving 'archive.ubuntu.com'`
**原因：** WSL2 NAT模式下未正确转发宿主机DNS
**解决：** 手动写入 `/etc/resolv.conf`：
```bash
nameserver 223.5.5.5
nameserver 8.8.8.8
```
**备注：** apt update仍然很慢（超时），但ping已通。后续用清华镜像源绕过。

#### 问题2：pip无法安装（PEP 668）
**现象：** `python3 -m pip install flask` 报 `No module named pip`
**原因：** Ubuntu 26.04系统Python不自带pip，且PEP 668禁止直接pip install到系统目录
**解决：**
```bash
curl -sSL https://bootstrap.pypa.io/get-pip.py -o /tmp/get-pip.py
python3 /tmp/get-pip.py --break-system-packages -i https://pypi.tuna.tsinghua.edu.cn/simple
```
**备注：** Flask最终发现系统已自带（python3-flask包），无需pip安装。

#### 问题3：Heredoc在WSL2中转义失败
**现象：** 用PowerShell调用WSL的bash heredoc写C源文件，反斜杠和引号被吞掉
**原因：** PowerShell→WSL→bash 三层转义，字符串中的`"`和`\`全部被破坏
**解决：** 改用 `apply_patch` 工具直接在Windows端写文件，再 `cp` 到WSL2

#### 问题4：JSON在shell命令中转义失败
**现象：** `mosquitto_pub -m '{"device":"stm32"}'` 中的引号被PowerShell/WSL吞掉
**原因：** 同问题3，多层shell转义
**解决：** 用 `mosquitto_pub -f /tmp/msg.txt` 从文件发送，避免内联JSON

#### 问题5：后台进程输出丢失
**现象：** `./gateway &` 后台运行后，sqlite3查询报 `no such table: sensor`
**原因：** 后台进程的工作目录和输出流与前台shell不同，导致路径错乱
**解决：** 用绝对路径 `sqlite3 /home/sunsuming/iot-gateway/build/sensor.db`，日志重定向到文件 `./gateway > /tmp/gw.log 2>&1 &`

### 4. 项目架构

```
STM32G431 ──UART──→ ESP8266 ──WiFi/MQTT──→ Linux Gateway
  ADC采集              透传桥接              ┌─ MQTT线程(订阅)
  温度/光照                                  ├─ 环形缓冲区(mutex+cond)
                                             ├─ DB线程(SQLite写入)
                                             ├─ TCP线程(:8888)
                                             └─ Flask(:5000) Web仪表盘
```

### 5. 线程同步机制

| 线程 | 读写 | 同步方式 |
|------|------|----------|
| MQTT→环形缓冲区 | 写 | pthread_mutex + pthread_cond |
| DB←环形缓冲区 | 读 | pthread_cond_timedwait(500ms超时) |
| TCP←latest | 读 | pthread_mutex |
| main→running | 写 | volatile int |
